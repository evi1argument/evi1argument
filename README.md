# Evil Argument

Делаю инструменты для Telegram и своих серверов. Автоматизирую задачи, которые приходится повторять вручную.

## Чем занимаюсь

- **Telegram** — боты, автомодерация и инструменты для админов сообществ.
- **Свои серверы** — развёртывание сервисов, мониторинг и повседневная автоматизация.

## Сейчас в работе

**TG-Sentinel** — бот и веб-панель для админов Telegram-сообществ. Помогает модерировать чаты и отвечать на обращения участников в одном месте.
